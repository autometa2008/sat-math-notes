Desmos Basics

  • Desmos only knows x and y. Swap every letter: the input becomes x, the output becomes y.
    Example: h = −16t² + 64t → type y=-16x^2+64x
  • Click the gray dots to see exact points.
  • Can't see the graph? Zoom out.
  • Trig in degrees? Wrench icon → Degrees (or Radians to match the problem).
  • Math with no x or y (like 48/0.8) just gives you the answer, like a calculator.

How to type it

^ exponent

x² → x^2

sqrt() square root

√(x+7) → sqrt(x+7)

pi for π

3π → 3pi

abs() absolute value

|2x−3| → abs(2x-3)

>= and <=

for ≥ and ≤

~ regression

for "line from points"

The 9 Moves

These solve most of the test. Learn them like dance moves.

1

Solve

Type y=left side and y=right side. Click where they cross. The x is your answer.

2

Zeros

Type y=.... Click where it crosses the x-axis.

3

Min / Max

Type y=.... Click the top or bottom tip.

4

System

Type both equations exactly as given. Click where they cross.

5

Plug In

Type f(x)=..., then f(4).

6

Slider

Unknown letter (k, c, a)? Add a slider and drag until it does what the question says.

7

Find the Letter

Plug in the number you know, swap the letter for x, type y=..., click the x-intercept.

8

Match

Graph the question and each choice. The one that lands exactly on top wins. For number answers, type each choice and compare decimals.

9

Line from Points

Add a table, enter the points, type y_1 ~ mx_1 + b.

How to Spot Each Type

QuadraticHas x², even hidden: (x+2)(x−3), (x−3)², x(x+4). U-shaped graph. Anything thrown or launched. Length × width area problems.
ExponentialThe letter is up in the exponent. Words: "% per year," "doubles," "half-life."
Polynomialx³ or higher, p(x), the word "factor."
Radical / Rationalx inside a √, or x on the bottom of a fraction. Use Move 1. Desmos skips fake answers. No crossing = no solution.
Functionf(x) is a name, not f times x. "f(3)" on a graph = the y-value at x = 3.
CircleHas both x² and y².
Trigsin, cos, tan, or a right triangle with lettered corners.
RadiansAn angle with π and no ° symbol.

unit 1

Algebra

Lines

  • y = mx + b
  • m = the "per" amount (per hour, per month)
  • b = the start or flat fee
  • C = 30h + 50 → $30 per hour, $50 fee

Slopes

  • Parallel = same slope
  • Perpendicular = flip it + change the sign
    2 → −1/2

Systems

  • No solution = parallel lines
  • Infinite solutions = same line
  • Check if they want x + y, not just x!

Inequalities

  • × or ÷ by a negative → flip the sign
  • ≥ or ≤ = solid line
  • > or < = dashed line

Absolute value

Usually 2 answers. Type y=abs(2x-3) and y=7, then click both crossings.

unit 2

Advanced Math

Quadratic forms

y = ax² + bx + cc is the y-intercept
y = (x − 2)(x + 5)zeros are 2 and −5 (flip signs)
y = a(x − h)² + kvertex is (h, k) (flip h)
a is negativeopens down, has a maximum

How many solutions?

  • Crosses the x-axis twice → 2
  • Just touches → 1
  • Never touches → 0

Exponent rules

  • x² · x³ = x⁵ (add)
  • x⁵ / x² = x³ (subtract)
  • (x³)² = x⁶ (multiply)
  • x⁻² = 1/x² (negative = flip)
  • x1/2 = √x · x2/3 = ∛(x²)
  • Or just use Move 8!

Exponential growth & decay

  • y = a(b)t → a = the start
  • 1.04 = grows 4% · 0.85 = shrinks 15%
  • 300(2)t/3 = doubles every 3
  • 80(1/2)t/10 = halves every 10
  • "by 50 each year" = linear · "by 5% each year" = exponential

Factors

(x − 3) is a factor = 3 is a zero = p(3) = 0

Flip the sign!

Moving graphs

  • f(x) + 3 → up 3
  • f(x − 3) → right 3 (backwards!)
  • −f(x) → flips upside down
Line + parabola together? Type both and click where they cross (Move 4).

unit 3

Data & Problem Solving

Percents

  • Move the decimal 2 left: 5% = 0.05, 150% = 1.5
  • "Of" means multiply
  • 30% off → × 0.7
  • 30% increase → × 1.3
  • Find the original → divide (48 ÷ 0.8)
  • % change = (new − old) ÷ old
  • +20% then −20% is NOT even: 1.2 × 0.8 = 0.96

Ratios & rates

  • Rate = anything with "per"
  • Same thing on top: flour/sugar = flour/sugar
  • 3:5 out of 40 → 3/8 × 40 = 15

Unit conversions

  • Multiply by fractions so units cancel
  • 60 mph → ft/sec: 60*5280/3600 = 88

Stats words

  • Mean = average · Median = middle (in order) · Mode = most common · Range = biggest − smallest
  • Standard deviation = spread. Clumped = small, spread out = big. Just compare.
  • An outlier moves the mean a lot and the median barely
  • Total = mean × count (for missing-number problems)
  • Frequency 5 = that number appears 5 times

Reading graphs

  • Dot plot: each dot = 1 data point
  • Histogram: bar height = how many
  • Box plot: whisker ends = min & max, box edges = Q1 & Q3, middle line = median

Scatterplots

  • Dots go up = positive · down = negative
  • Predict = plug x into the line
  • Slope = "for each 1 more x, y changes by the slope"
  • y-intercept = predicted y when x = 0
  • Actual − predicted = dot minus line

Probability & tables

What you want ÷ total. If it says "of the ___" or "given ___", that group is the bottom number.

Studies (pick the most careful answer)

  • Random sample → results apply to that group only
  • Random assignment → you can say "causes"
  • Neither → only "associated"
  • Bigger sample = smaller margin of error
  • 45% ± 3 → really between 42% and 48%
  • Only surveying one kind of person (like gym-goers) = biased

unit 4

Geometry & Trig

Use the reference sheet in the test app. It has the area and volume formulas and special triangles.

Angles

  • Line = 180 · Triangle = 180 · Around a point = 360
  • Supplementary = add to 180
  • Complementary = add to 90
  • Vertical angles (X shape) = equal
  • Parallel lines + a line through them: only big and small angles. Big + small = 180.

Triangles

  • Hypotenuse: sqrt(a^2+b^2)
  • Missing leg: sqrt(c^2-a^2)
  • Triples: 3-4-5, 5-12-13, 8-15-17 (and doubles like 6-8-10)
  • 30-60-90: x, x√3, 2x
  • 45-45-90: x, x, x√2
  • Isosceles: 2 equal sides = 2 equal angles
  • Equilateral: all angles 60°

Similar triangles

  • Same shape, different size → small/big = small/big
  • Clues: a small triangle inside a big one, shadows, the word "similar"
  • Match letters in order: A↔D, B↔E, C↔F

Area & volume

  • Area = flat space (ft²)
  • Volume = 3D space (ft³)
  • Perimeter = distance around
  • Double the sides → area × 4, volume × 8

Circle parts

  • Diameter = 2r
  • Circumference = 2πr
  • Area = πr²
  • Tangent line makes 90° with the radius

Circle equation

(x − h)² + (y − k)² = r²

  • Center (h, k) with flipped signs
  • Radius = √ of the right side (25 means r = 5)
  • Messy version? Just type it into Desmos.
  • Arc = (angle/360) × 2πr · Sector = (angle/360) × πr²
  • In radians: arc = r × angle

Trig: SOH CAH TOA

  • Sin = Opp / Hyp · Cos = Adj / Hyp · Tan = Opp / Adj
  • Stand at the angle: Opposite = across, Adjacent = next to, Hypotenuse = longest
  • Opposite and adjacent swap for the other angle
  • No picture? Draw one. cos B = 5/13 → sides 5, 12, 13
  • sin(a) = cos(b) → a + b = 90
  • Know one ratio, need another: sin(arccos(5/13)), then match the decimal

Traps & Test Day

Traps

  • Read the last line twice. They often ask for x + y, 2x, or y instead of x.
  • Desmos gives a decimal? Type the answer choices to find the match.
  • Type-in answers: fractions OK (2/3), negatives OK.
  • Radius² = 25 means radius = 5.

Strategy

  • 2 modules · 22 questions · 35 min each
  • About 1.5 minutes per question
  • Stuck? Flag it, guess, move on.
  • Never leave a blank. No penalty for guessing.
  • Practice full tests in Bluebook.
